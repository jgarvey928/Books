### 📐 Architecture & System Design
Books focused on high-level system structures, distributed systems, and architectural patterns.
* **[Clean Architecture: A Craftsman's Guide to Software Structure and Design](Clean%20Architecture%20A%20Craftsman's%20Guide%20to%20-%20Robert%20C.%20Martin.epub)** - *Robert C. Martin*
* **[Designing Data-Intensive Applications](Designing%20Data%20Intensive%20Applications.pdf)** - *Martin Kleppmann*
* **[Domain-Driven Design: Tackling Complexity in the Heart of Software](Domain%20Driven%20Design%20Tackling%20Complexity%20in%20the%20Heart%20of%20Software%20-%20Eric%20Evans.pdf)** - *Eric Evans*
* **[Software Architecture in Practice (4th Edition)](software-architecture-in-practice-4.pdf)** - *Len Bass, Paul Clements, Rick Kazman*

### 🧩 Design Patterns & Principles
Resources for solving common software design problems using proven patterns.
* **[Design Patterns: Elements of Reusable Object-Oriented Software (GoF)](Design-patterns-elements-of-reusable-object-oriented-software-Erich-Gamma-Richard-Helm.epub)** - *Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides*
* **[Head First Design Patterns (2nd Edition)](Head_First_Design_Patterns_Building_Extensible_and_Maintainable_Object-Oriented_Software_2nd_Edition.pdf)** - *Eric Freeman, Elisabeth Robson*
* **[Dependency Injection Principles, Practices, and Patterns](Dependency%20Injection%20-%20Principles%20Practices%20and%20Patterns%20-%20Steven%20van%20Deursen.epub)** - *Steven van Deursen, Mark Seemann*
* **[Hands-On Design Patterns with Swift](Hands-On%20Design%20Patterns%20with%20Swift.pdf)** - *Paco L. Perez*

### 🧼 Clean Code & Craftsmanship
Guides on writing readable, maintainable, and elegant code.
* **[Clean Code: A Handbook of Agile Software Craftsmanship](Clean%20Code%20Collection%20-%20Robert%20C.%20Martin.epub)** - *Robert C. Martin*
* **[The Pragmatic Programmer: Your Journey to Mastery](The%20Pragmatic%20Programmer%20Your%20Journey%20to%20Mastery,%2020th%20Anniversary%20Edition%20by%20Andrew%20Hunt%20David%20Hurst%20Thomas.pdf)** - *David Thomas, Andrew Hunt*
* **[Refactoring: Improving the Design of Existing Code](Refactoring%20Improving%20the%20Design%20of%20Existing%20Code.epub)** - *Martin Fowler*
* **[Five Lines of Code: How and when to refactor](Five%20Lines%20of%20Code_%20How%20and%20when%20to%20refactor.epub)** - *Christian Clausen*
* **[Software Design Decoded: 66 Ways Experts Think](Software-design-decoded-66-ways-experts-think.pdf)** - *Marian Petre, André van der Hoek*

### 🔄 Methodologies & Testing (Agile/TDD)
Books covering modern software development lifecycles, extreme programming, and test-driven approaches.
* **[Test-Driven Development: By Example](Test-Driven%20Development%20By%20Example%20(Kent%20Beck).pdf)** - *Kent Beck*
* **[Growing Object-Oriented Software, Guided by Tests](Growing%20Object-Oriented%20Software,%20Guided%20by%20Tests.pdf)** - *Steve Freeman, Nat Pryce*
* **[Agile Software Development: Principles, Patterns, and Practices](Agile%20Software%20Development.pdf)** - *Robert C. Martin*
* **[Extreme Programming Explained: Embrace Change (2nd Edition)](Extreme-programming-explained-embrace-change-2.pdf)** - *Kent Beck*
* **[Use-Case 2.0](use-case_2.0_final_rev3.pdf)** - *Ivar Jacobson, Ian Spence, Kurt Bittner*
* **[The Essentials of Modern Software Engineering](the-essentials-of-modern-software-engineering-free-the-practices-from-the-method-prisons.epub)** - *Ivar Jacobson, Harold "Bud" Lawson, Pan-Wei Ng, Paul E. McMahon, Michael Goedicke*

* **[Object-Oriented Software Construction](Object%20Oriented%20Software%20Construction-Meyer.pdf)** - *Bertrand Meyer*
